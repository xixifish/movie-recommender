# Popcorn user test

## Before they arrive

- [ ] Search once on the live site, so the server is awake
- [ ] Clear the browser: Application, Local Storage, delete `saved`,
      `hint.films`, `hint.saved`. They should see it as a first-time visitor
- [ ] Open the site at the top of the page

## What to say

> "Find a film you would want to watch tonight."

No explanation about the interface. User's hesitation is the finding.

## Each round

| round | what they typed | screens marked | liked | disliked | saved | already seen |
| ----- | --------------- | -------------- | ----- | -------- | ----- | ------------ |
| 1     |                 |                |       |          |       |              |
| 2     |                 |                |       |          |       |              |
| 3     |                 |                |       |          |       |              |
| 4     |                 |                |       |          |       |              |

**already seen** = how many films on that screen the user had already watched.
The measure is saves divided by the ones they had not.

round 1 saved ** of ** unwatched
round 2 saved ** of ** unwatched
round 3 saved ** of ** unwatched

Rising is the loop working. Flat means the marks are doing nothing.

## When the user stops saving

> "You didn't save any that time. Was there nothing you liked, or did you already have enough?"

Then note: did they keep refreshing, or stop? \_\_

And did the last screen still look like the films they saved, or had it
drifted? \_\_

## Watch for

- [ ] Did they find the marking on their own? How long did it take?
- [ ] Did they press Refresh without being told?
- [ ] Did they use the search box, or only the example chips?
- [ ] 48 films is eight rows. Did they scroll to the bottom, or stop early?
- [ ] Did they open an overview? Did it help?
- [ ] Did they notice the Saved tab?
